# Legacy Node Notes

This folder keeps historical node-specific notes that were created while this
repository was also being used as an operational workspace for specific
SitioUno/OpenClaw nodes.

These files are retained for context only. They are not the canonical source for
the reusable OpenClaw Office fork.

## Current Boundary

- This repository is the node-agnostic OpenClaw Office UI/product fork.
- New or current node runbooks, fleet registry details, MCP routing, delegate
  receiver code, infrastructure, and per-node operational notes belong in
  `gcloud-office`.
- Hermes/Zeus implementation details belong in `hermes-agent`.
- MiroFish product details belong in `mirofish-original-ai-forecast`.
- Software Factory implementation details belong in
  `sitiouno-software-factory-ai`.

## Archived Material

- `SICILIA-NODE.md` - historical Sicilia node installation notes.
- `HERMES-NODE.md` - historical Hermes/Zeus node notes.
- `MIROFISH-NODE.md` - historical MiroFish node notes.
- `onboard-sicilia-prompt.md` - original Sicilia onboarding prompt.
- `hermes-config/` - historical Hermes identity/config snapshot.
- `hermes-openclaw-tools/` - historical Hermes MCP/fleet tooling snapshot.
- `docs/` - historical delegation plans, registry roadmap, and RPC survey notes.

Before reusing anything here, check the canonical repo listed in
`SITIOUNO-REPO-MAP.md`.
